# Онлайн-дизасемблер

Кросплатформений інтерактивний онлайн-дизасемблер для зворотної розробки.

## Можливості

- Завантаження та аналіз ELF-файлів (Linux)
- Дизасемблювання секції .text через Capstone Engine
- Побудова та інтерактивна візуалізація графа потоку керування (CFG)
- Кольорове підсвічування синтаксису асемблера за типом інструкцій
- Двонаправлена навігація між асемблерним кодом та CFG
- Експорт результатів у JSON та текстовому форматі

## Технологічний стек

| Компонент | Технологія |
|-----------|-----------|
| Backend | Python 3, FastAPI, Uvicorn |
| Дизасемблювання | Capstone Engine |
| Парсинг ELF | LIEF |
| Frontend | HTML, CSS, JavaScript |
| Візуалізація CFG | Cytoscape.js + dagre |

## Встановлення та запуск

### Передумови

- Python 3.10 або новіший
- pip (менеджер пакетів Python)
- Git

### Крок 1: Клонування репозиторію

```bash
https://github.com/trompakandrij-eng/online-disassembler
```

### Крок 2: Встановлення залежностей

```bash
pip install fastapi uvicorn capstone lief python-multipart
```

### Крок 3: Запуск сервера

```bash
python main.py
```

Або на Windows:

```bash
py -3 main.py
```

### Крок 4: Відкриття у браузері

Перейти за адресою: http://127.0.0.1:8000

## Використання

1. Перетягніть ELF-файл у зону завантаження або натисніть «Обрати файл»
2. Після аналізу відкриється панель з дизасемблованим кодом
3. Використовуйте кнопки «Асемблер», «CFG» або «Обидва» для перемикання режимів
4. Клацніть на вузол CFG для переходу до відповідного коду
5. Експортуйте результати через кнопки «Експорт JSON» або «Експорт текст»
